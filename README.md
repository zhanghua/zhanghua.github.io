# 书法字帖临摹对比工具

自动切割书法字帖和临摹作品中的单字，逐字并排对比。支持竖排（传统书法）和横排（练习纸）两种排列方向的2D自动分割。

## 功能特点

- **2D自动分割**：基于投影分析自动检测行/列和单字边界
- **竖排支持**：传统书法从右到左、从上到下的阅读顺序
- **横排支持**：练习纸从上到下、从左到右的阅读顺序
- **自适应阈值**：自动适应深色/浅色背景，处理不同拍摄条件
- **可选参数提示**：可手动指定行/列数和每行/列字数（0=自动检测）
- **下载对比图**：一键导出PNG格式的逐字对比图
- **滚轮缩放**：在结果区域滚动鼠标滚轮可缩放查看
- 字帖原字（红框）和临摹作品（绿框）清晰区分

## 使用方法

1. 在浏览器中打开 `index.html`
2. 上传字帖原作图片，选择排列方向（竖排/横排）
3. 上传临摹作品图片，选择排列方向
4. （可选）输入行/列数和每行/列字数提示，0表示自动检测
5. 点击「自动切割对比」按钮
6. 查看逐字对比结果，可用滚轮缩放
7. 点击「📥 下载对比图」保存PNG

## 适用场景

- 字帖原稿：竖排传统书法（楷书、行书、草书等）
- 临摹作品：横排练习纸上的单字临摹
- 通临作品：竖排临摹整篇作品

## 技术栈

- HTML5 Canvas
- CSS3
- JavaScript (ES6+)
- 纯前端，无需服务器

## 浏览器要求

支持 JavaScript 和 Canvas 的现代浏览器（Chrome、Edge、Firefox 等）

## 本地运行

无需构建，直接在浏览器中打开 `index.html` 即可。

## 使用技巧

- 拍照时保持光线均匀，避免阴影和透视变形
- 确保整个作品都在画面内
- 自动检测效果不佳时，可手动输入行/列数和字数提示
- 草书等笔画连绵的字体建议手动指定每行/列字数
